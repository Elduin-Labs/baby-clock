# Baby Clock

A clock that turns you into a baby! Use it and it starts ticking, and with
every tick you get a little smaller until you're a tiny baby. While you're a
baby your mouth hangs open and you drool all over yourself. Use the clock
again to tick back up into a grown-up.

Craft it from a clock and a milk bucket.

Fabric, for Minecraft 1.21.11 and 26.2. Needs Fabric API. Put it on the server
and in your game.
